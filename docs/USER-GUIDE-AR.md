## 🏢 الشركات (Multi-Company)

النظام يدعم **شركة قابضة + شركات تابعة** (Multi-Company):

```
Holding (شركة الفجر القابضة)
   ├── شركة الفجر للتجارة
   ├── شركة بنغازي للمقاولات
   └── شركة عائلتي
```

### تبديل الشركة النشطة
1. اضغط على **اسم الشركة** في الشريط العلوي (مثل "Holding Enterprise")
2. اختر الشركة من القائمة
3. البيانات في كل الصفحات تتحدث فوراً

> ⚠️ **مهم:** كل البيانات مفصولة بـ `company_id` — لا يمكن رؤية بيانات شركة أخرى دون صلاحية.

## 💰 المالية والمحاسبة (Finance)

### الحسابات (47 حساب)
يأتي النظام مع **دليل حسابات كامل** (شجرة):
- `1000` الأصول
  - `1100` أصول غير متداولة (عقارات، مركبات)
  - `1200` أصول متداولة (نقدية، بنك، مدينون)
- `2000` الالتزامات
- `3000` حقوق الملكية
- `4000` المصروفات
- `5000` الإيرادات

### القيود المحاسبية
كل عملية مالية تنشئ **قيد محاسبي متوازن** (مدين = دائن):

**مثال: فاتورة مبيعات 1,150 د.ل (شامل ضريبة 15%)**
- مدين: 1230 ذمم مدينة — 1,150 د.ل
- دائن: 4100 إيرادات — 1,000 د.ل
- دائن: 2250 ضريبة مستحقة — 150 د.ل

### التقارير المالية (20+)

#### 1. ميزان المراجعة (Trial Balance)
- يعرض كل حساب مع الرصيد المدين والدائن
- **يُتحقق من:** `مجموع المدين = مجموع الدائن`

#### 2. الميزانية العمومية (Balance Sheet)
- **الأصول** = الالتزامات + حقوق الملكية
- تاريخ: `?asOf=YYYY-MM-DD`

#### 3. قائمة الدخل (Income Statement)
- الإيرادات − المصروفات = صافي الربح
- فترة: `?from=YYYY-MM-DD&to=YYYY-MM-DD`

#### 4. قائمة التدفقات النقدية (Cash Flow)
- تشغيلية، استثمارية، تمويلية

#### 5. تقرير ضريبة القيمة المضافة (VAT)
- ضريبة المخرجات (15%) − ضريبة المدخلات = الضريبة المستحقة

## 👥 العملاء (Customers)

### إنشاء عميل
1. اذهب إلى **المالية → العملاء**
2. اضغط **عميل جديد** (أعلى اليسار)
3. املأ الحقول:
   - **الاسم** (مطلوب)
   - **الاسم الإنجليزي**
   - **الرقم الضريبي**
   - **البريد الإلكتروني**
   - **الهاتف**
   - **العنوان**
   - **حد الائتمان** (الافتراضي: 50,000 د.ل)
   - **شروط الدفع** (بالأيام، الافتراضي: 30)
4. اضغط **حفظ**

### فاتورة مبيعات
1. اذهب إلى **المالية → فواتير المبيعات**
2. اضغط **فاتورة جديدة**
3. اختر العميل
4. أضف البنود (صنف، كمية، سعر)
5. يتم حساب الضريبة (15%) والمجموع تلقائياً
6. اضغط **حفظ ثم ترحيل** لإنشاء القيد المحاسبي

### تقرير أعمار الديون (AR Aging)
- يعرض المبالغ المستحقة: 0-30 يوم، 31-60، 61-90، 90+
- يساعد في متابعة التحصيل

## 🏭 الموردون والمشتريات (Procurement)

### تدفق العمل الكامل:
```
طلب شراء (PR) → أمر شراء (PO) → استلام بضاعة (GR) → فاتورة مورد (Bill) → دفع
```

### أوامر الشراء (PO)
1. **المشتريات → أوامر الشراء → جديد**
2. اختر المورد
3. أضف البنود
4. **إرسال للمورد** (Status: Sent)
5. المورد يؤكد

### استلام البضاعة (GR)
1. **المشتريات → سندات الاستلام → جديد**
2. اختر الأمر (PO)
3. حدد الكميات المستلمة
4. **استلام** — يتم تحديث المخزون تلقائياً

### فاتورة المورد (Bill)
1. **المشتريات → فواتير الموردين → جديد**
2. اختر المورد و GR
3. **ترحيل** — قيد: مدين مصروف + مدين ضريبة، دائن موردون

## 📦 المخزون (Inventory)

### الأصناف
- **20 صنف** افتراضي (إلكترونيات، أغذية، مواد بناء)
- كل صنف له: SKU، باركود، فئة، وحدة، سعر تكلفة، سعر بيع

### حركات المخزون
- كل حركة تُسجَّل (وارد، صادر، تحويل، تعديل)
- الرصيد الحالي = مجمع الحركات

### تقرير تقييم المخزون
- `التقارير → تقييم المخزون`
- يعرض الكمية × متوسط التكلفة = القيمة الإجمالية

## 👨‍💼 الموارد البشرية (HR)

### الموظفون
- **8 موظفين** افتراضياً
- لكل موظف: رقم، اسم، رقم وطني، بريد، قسم، راتب أساسي

### مسير الرواتب (Payroll)
- شهري لكل موظف
- خصم ضريبة 5%
- قيد: مدين رواتب، دائن نقدية

### طلبات الإجازة
1. **الموارد البشرية → طلبات الإجازة**
2. الموظف يقدم طلب (يمكن تحديد عدة طلبات)
3. **الموافقة المجمعة:** حدد طلبات → اضغط "موافقة المحدد"
4. **رفض المحدد** متاح أيضاً

### الحضور
- تسجيل يومي (حاضر، غائب، إجازة)

## ❓ الأسئلة الشائعة

**س: نسيت كلمة المرور؟**
ج: تواصل مع مدير النظام لإعادة التعيين عبر `/admin/users`.

**س: كيف أضيف مستخدم جديد؟**
ج: **الإدارة → المستخدمون → مستخدم جديد**. يجب تحديد دور (Admin, Accountant, ProjectManager, Viewer).

**س: كيف أعمل نسخة احتياطية؟**
ج: `pg_dump -U erp_user erp_system_demo > backup.sql` (اطلب من مدير النظام).

**س: الضريبة 15% قابلة للتغيير؟**
ج: حالياً ثابتة على 15% (معيار ليبيا). يمكن تعديلها في الكود إذا لزم.
