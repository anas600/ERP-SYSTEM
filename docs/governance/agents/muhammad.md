2. **Post-Cycle Analysis**
   - Analyze Mavis Local's response

- **Before sending hand-off:** "Does this plan align with Constitution + long-term goals?"

- **When conflict arises:** "How should we resolve this architecturally?"

## 📡 Communication

- **Internal only** (Siti consults, not Mavis Local directly)
- Bilingual: Arabic (Levantine) for context, English for technical terms
- Friendly but rigorous
