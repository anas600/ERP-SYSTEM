## Migration Pattern (canonical example)

**Before (entity with TenantId):**
```csharp
public class Customer
{
    public Guid Id { get; set; }
    public Guid TenantId { get; set; }  // ← REMOVE THIS LINE
    public string Name { get; set; }
    public string Email { get; set; }
    public bool IsActive { get; set; }
}
```

**After:**
```csharp
public class Customer
{
    public Guid Id { get; set; }
    public string Name { get; set; }
    public string Email { get; set; }
    public bool IsActive { get; set; }
}
```

**Before (repo with tenantId):**
```csharp
public async Task<Customer?> GetByIdAsync(Guid tenantId, Guid id, CancellationToken ct)
{
    using var conn = await _db.CreateOltpConnectionAsync(ct);
    return await conn.QueryFirstOrDefaultAsync<Customer>(new CommandDefinition(
        @"SELECT * FROM customers WHERE id = @Id AND tenant_id = @TenantId",
        new { Id = id, TenantId = tenantId },
        cancellationToken: ct));
}
```

**After:**
```csharp
public async Task<Customer?> GetByIdAsync(Guid id, CancellationToken ct)
{
    using var conn = await _db.CreateOltpConnectionAsync(ct);
    return await conn.QueryFirstOrDefaultAsync<Customer>(new CommandDefinition(
        @"SELECT * FROM customers WHERE id = @Id",
        new { Id = id },
        cancellationToken: ct));
}
```

**Before (service with tenantId):**
```csharp
public class CustomerService
{
    private readonly ICustomerRepository _repo;
    private readonly ITenantContext _tenantContext;
    
    public async Task<CustomerDto> GetAsync(Guid id, CancellationToken ct)
    {
        var tenantId = _tenantContext.TenantId 
            ?? throw new InvalidOperationException("Tenant not resolved");
        var customer = await _repo.GetByIdAsync(tenantId, id, ct);
        return MapToDto(customer);
    }
}
```

**After:**
```csharp
public class CustomerService
{
    private readonly ICustomerRepository _repo;
    private readonly ICompanyContext _companyContext;
    
    public async Task<CustomerDto> GetAsync(Guid id, CancellationToken ct)
    {
        var customer = await _repo.GetByIdAsync(id, ct);
        return MapToDto(customer);
    }
}
```

**For Controllers (auth context):**

**Before:**
```csharp
public class CustomersController : ControllerBase
{
    private readonly ITenantContext _tenantContext;
    
    [HttpGet("{id}")]
    public async Task<ActionResult<CustomerDto>> Get(Guid id, CancellationToken ct)
    {
        var tenantId = _tenantContext.TenantId
            ?? throw new InvalidOperationException("Tenant not resolved");

**After:**

{

        return Ok(dto);
    }
}
```
